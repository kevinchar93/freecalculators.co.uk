## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The payment schedule (payment-schedule-section.tsx) currently scrolls the whole table including its header row. Make it read as an accordion where the column headings stay fixed while only the rows scroll within the max-height area.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Column headers (Month / Interest / Principal / Balance) remain visible while the schedule body scrolls
- [x] #2 The section expands and collapses like an accordion
- [x] #3 Layout works on mobile and desktop widths
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Rebuilt trigger as a plain CollapsibleTrigger button with a group-controlled ChevronDownIcon (rotates 180deg on data-state=open) instead of the Button component, so the header/body share one bordered box (overflow-hidden rounded-md border) with no visual gap. Table header cells use sticky top-0 bg-background inside the CollapsibleContent, which keeps max-h-85 overflow-auto as the single scroll container, so only rows scroll while headers stay pinned. Verified with Playwright screenshots against the running dev app at /calculators/mortgage: closed state, open state showing header/body joined with no gap and arrow flipped up, scrolled state showing sticky header persisting while rows changed (Oct '26 rows -> Jul '27 rows), and a 390px mobile viewport open state. tsc --noEmit, eslint, and prettier all pass on the changed file.
<!-- SECTION:NOTES:END -->
