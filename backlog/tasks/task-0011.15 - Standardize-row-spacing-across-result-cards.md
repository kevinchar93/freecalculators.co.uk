## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Vertical spacing between rows inside each result card's breakdown list is inconsistent: Your Results uses a wider gap than During-deal/After-deal/Summary, and bold summary rows (Total paid, Remaining balance, date rows) don't have a deliberately larger gap than the plain rows around them. Tighten the gap between non-bold breakdown rows and give bold rows a consistently larger (but still modest) gap, the same way in all four cards.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Non-bold breakdown rows use the same, tighter row gap in all four cards (Your Results, During-deal, After-deal, Summary)
- [ ] #2 Bold rows (Total paid/Total Paid, Remaining balance, date rows) use a consistently larger gap between each other than the non-bold rows use, the same way in all four cards
- [ ] #3 Underlying values, labels, and row order are unchanged; only spacing (and, where needed to make spacing consistent, which rows sit inside vs. outside the breakdown dl) changes
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. single-result-card.tsx: change dl gap-2 -> gap-1 (tight, non-bold rows). Wrap the Total Paid row + date row together in a new 'flex flex-col gap-2' div (bold-row gap), replacing their previous reliance on the outer gap-4 container.
2. during-deal-card.tsx: dl stays gap-1. Wrap Total paid + Remaining balance + date row together in a new 'flex flex-col gap-2' div.
3. after-deal-card.tsx: move Total paid out of the dl (it was the dl's last, bold, border-topped row) into a new bold-rows wrapper alongside the date row, both under 'flex flex-col gap-2', preceded by the same divider pattern used in the other cards. dl keeps gap-1 with only its non-bold rows.
4. summary-card.tsx: move Total Paid out of the dl into its own bold row below a divider (same pattern). Give the card's content div 'flex flex-col gap-4' (matching the other cards' major-section spacing) and drop the vehicle notice's manual mt-4 in favor of the gap.
5. Verify: npx vitest run, npm run types:check, Playwright visual check of all four cards in both repayment and interest-only states.
